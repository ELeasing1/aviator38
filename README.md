# Сайт Стоматологический центр «Авиатор»

Эта папка — готовый сайт. Скопируйте её содержимое в репозиторий GitHub (или на любой хостинг) — сайт заработает сразу, ничего настраивать и устанавливать не нужно.

## Что в папке

| Файл | Зачем |
| --- | --- |
| `index.html` | Весь сайт: страницы, фотографии, документы, поиск и помощник в одном файле |
| `404.html` | Страница для неверного адреса — отправляет посетителя на главную |
| `robots.txt` | Разрешение для поисковых систем индексировать сайт |
| `.nojekyll` | Техничес­кий файл GitHub Pages (чтобы страницы отдавались как есть) |
| `admin/index.html` | Редактор сайта (админ-панель). Открывается двойным щелчком с диска и по адресу `.../admin/` после публикации |
| `Редактор сайта.html` | Ярлык: открывает тот же редактор из `admin/` |

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New**). Имя может быть любым, например `aviator-site`.
2. Загрузите в него **всё содержимое этой папки** (кнопка **Add file → Upload files**, затем **Commit changes**).
3. Откройте **Settings → Pages**. В разделе *Build and deployment* выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`. Нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

### Свой домен

В **Settings → Pages → Custom domain** укажите домен клиники и нажмите **Save** — GitHub сам добавит в репозиторий файл `CNAME`. У регистратора домена пропишите запись `CNAME` на `<ваш-логин>.github.io`. После проверки домена включите **Enforce HTTPS**. Файл `CNAME` в репозитории удалять нельзя — иначе домен отвалится (редактор при публикации его не трогает: он меняет только `index.html`).

## Админ-панель (редактор сайта)

После публикации она открывается по адресу `https://<ваш-домен>/admin/` и показывает ту версию сайта, которая сейчас опубликована. Редактор работает прямо в браузере: сервер и база данных не нужны.

### Автопубликация: кнопка сразу меняет сайт

Один раз настройте подключение к GitHub — дальше нажатие **«Опубликовать на сайте»** отправляет новый `index.html` в репозиторий, и сайт в интернете обновляется сам (обычно меньше минуты).

1. На github.com: фото профиля → **Settings** → внизу слева **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. **Expiration** — срок действия (например, 1 год). **Repository access** → **Only select repositories** → репозиторий сайта.
3. **Permissions → Repository permissions → Contents → Read and write**. Больше ничего включать не нужно.
4. **Generate token**, скопируйте строку (показывается один раз).
5. В редакторе: **Подключение к GitHub** → вставьте адрес репозитория и токен → **Проверить подключение** → **Сохранить настройки**.

Токен хранится только в браузере того компьютера, где его ввели (IndexedDB), и никогда не попадает в файлы сайта — на опубликованных страницах его нет. На чужом компьютере токен вводить не нужно: там сработает обычное сохранение файла. Отозвать доступ можно кнопкой «Удалить токен из браузера» и на github.com.

Если подключение не настроено, сохранение из интернета отдаёт новый `index.html`, который нужно загрузить в репозиторий (**Add file → Upload files**). А если открыть редактор из локальной папки (`admin/index.html` или ярлык «Редактор сайта.html»), файл перезаписывается прямо на диске.

Страница `/admin/` закрыта от поисковых систем (`robots.txt`), но доступна по ссылке всем. Посторонний сможет открыть редактор и сохранить себе копию сайта — **изменить опубликованный сайт он не может**: для этого нужен доступ к репозиторию. Если такая открытость не нужна, не выкладывайте папку `admin` (сайт работает и без неё).

## Как менять сайт

1. Откройте **«Редактор сайта.html»** двойным щелчком (Google Chrome, Microsoft Edge или Яндекс.Браузер) — или `admin/index.html`, или адрес `.../admin/` в интернете.
2. Внесите изменения: цены, услуги, врачи, тексты, фотографии, документы.
3. Нажмите **«Сохранить сайт»** — редактор перезапишет `index.html` в этой же папке (в первый раз браузер спросит, какой файл заменить, и попросит разрешение на запись).
4. Отправьте изменения в репозиторий: `git add .`, `git commit -m "Обновление сайта"`, `git push` — или через **Add file → Upload files** на сайте GitHub.

Документы PDF (договор, прайс-лист, положения, политика) собираются из текстов сайта автоматически в момент скачивания — отдельно обновлять их не нужно. Сканы (лицензия, выписка ЕГРЮЛ) хранятся внутри `index.html` как загруженные файлы.

## Важно

* Форм на сайте нет: персональные данные посетителей не собираются. Запись — по телефону, в WhatsApp и в регистратуре.
* Файл `Редактор сайта.html` можно не выкладывать в интернет: он нужен только на компьютере клиники. Если он опубликован, посторонние не смогут изменить сайт — только сохранить собственную копию.
* Перед публикацией убедитесь, что в редакторе на экране «Что заполнить» не осталось незакрытых пунктов.
